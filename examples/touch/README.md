# touch —— 原生触摸示例（工具链接口示例）

> ⚠️ **AI 生成 / 辅助创作：DeepSeek V4.1 Flash**（未人工审查）

**用途**：与 `../keys` 同一套原生钩子，核对**触摸**字段。

## 显示什么

| 行 | 含义 | ABI |
|---|---|---|
| `ty4=` | 触摸事件大类（= `0000000f`） | `*(u32*)(ev+4)` |
| `w7 =` | 动作：`1` 按下 / `2` 移动 / `8` 抬起 | `*(u32*)(ev+28)` |
| `w8 =` | 高 16 位 = **X** | `*(u32*)(ev+32)` |
| `w9 =` | **Y** | `*(u32*)(ev+36)` |

屏幕下方会在大字旁标出 X / Y（各 4 位十六进制），按住并拖动即可看到数值变化；
按住时还会在对应位置画一个十字（Y 落在 130..239 才画，避免与文字重叠）。

## 构建 / 部署

```bash
source ../../scripts/env.sh
make            # -> touch.elf
make deploy     # -> touch.hpappdir/
```

把 `touch.hpappdir/` 拷入计算器 `C:\DATA\` 运行。ESC / ON 退出。

## 备注

- 触摸的**外层事件类型**为 `15`（`hp_input.c` 同判据）；`w7` 的动作值 `1/2/8` 与
  `seek`/DOOM 的记录一致；
- 若你的固件报告不同值，以实测为准并更新 `hook_abi.md` 的「待确认」段。
